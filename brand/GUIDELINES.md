# Freelancer CRM: logo guidelines

## 1. The logo
- **Idea:** the F is a key you press. It stands for the keyboard-first way the app works.
- **Versions:** horizontal (default), stacked, symbol only.
- **Files:** `logo-*.svg` for the logo, `app-icon.svg` for app icons, `web/` for favicon and PWA icons.

## 2. Clear space
Keep a margin of **one stem width of the F** (about 1/8 of the symbol height) on all sides. The margin scales with the logo.

## 3. Minimum size
| Version | Screen |
|---|---|
| Horizontal | 120 px wide |
| Symbol | 24 px. Below that, use `logo-symbol-small.svg` (heavier F). Favicons use it. |

## 4. Colour
| Name | HEX | RGB |
|---|---|---|
| Cobalt | `#266df0` | 38, 109, 240 |
| Ink | `#10141c` | 16, 20, 28 |

Approved pairs: full colour on white, white version on cobalt or ink, black version on white.

## 5. Typography
Wordmark: Inter Semibold, converted to outlines (SIL Open Font License, free for logos). UI copy uses Inter, see `DESIGN.md`.

## 6. Don'ts
Don't stretch, rotate or recolour. No shadows, gradients or outlines. Don't retype the wordmark, use the SVG. Don't place the colour version on busy photos.
